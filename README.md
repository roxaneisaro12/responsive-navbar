# AUREL – Responsive Navigation Bar

## Project Overview

AUREL is a responsive navigation bar built with Vite and Tailwind CSS. It provides a simple, elegant navigation experience across desktop and mobile devices.

## Technologies Used

- HTML5
- Tailwind CSS v4
- JavaScript
- Vite
- Git and GitHub

## Features

- AUREL brand name and navigation links.
- Four navigation links: Home, About, Services and Contact.
- Responsive desktop navigation.
- Mobile hamburger menu that opens and closes.
- Menu automatically closes after selecting a mobile navigation link.
- Hover effects for navigation links.
- Visible keyboard focus styles for accessibility.
- Midnight and Champagne colour palette.

## Responsive Design

On desktop screens, the navigation links appear horizontally.

On smaller screens, the links are hidden behind a hamburger button. Clicking the button displays or hides the mobile menu.

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/roxaneisaro12/responsive-navbar.git`

2. Open the project folder:

   `cd responsive-navbar`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.

## Production Build

To create a production build, run:

`npm run build`
